# ADR SP-02 — Freeze Advisory Gate as Failed

## Hypothesis

The pinned Plonky3 commit contains every published upstream fix, and PQTC's custom codec/transcript avoids the fixed vulnerable classes.

## Exact assessment

The source-applicability matrix covers five public GHSAs and the separately documented malformed-proof panic issue. Upstream ancestry and pinned source show all five advisory patches. PQTC uses its own full-width typed transcript and strict proof codec, so each custom path requires project-specific regressions rather than an automatic upstream disposition.

## Assumptions

- Public GitHub advisories and the pinned repository README are complete for public information at the cutoff.
- The frozen v0.3 source and pinned dependency commit are the assessed code.
- Serialized proof rejection does not imply panic-freedom for every in-memory proof object.

## Alternatives considered

1. Mark the gate passed because all five GHSA patches are present. Rejected: the upstream panic warning remains and the custom verifier is not covered automatically.
2. Modify v0.3 to add unwind containment. Rejected in this research package: v0.3 is frozen and this program is not a new custody build.
3. Ignore native verifier availability because Solidity moves value. Rejected: operational proving/verification APIs accept untrusted proof bytes and are required deliverables.

## Measurements

Focused regression results are generated by `run_regressions.py` and preserved in `regression-results.json`. The assessment is source- and behavior-based; it has no gas claim.

## Gate result

**FAIL.** High-severity malformed-proof panic behavior is applicable or uncertain at the accepted native boundary. Candidate integration stops. Isolated benchmark-only work remains allowed.

## Compatibility consequences

A future engineering specification must add a panic-containment boundary or establish panic-freedom for all codec-reachable proofs, then rerun native and Solidity malformed-input suites. The fix must not alter proof transcript semantics silently.

## Review required

Independent review of transcript observation order, proof shape coverage, and unwind containment remains required. No security qualification follows from this ADR.
